## The First 7 Days Determine Whether a Client Stays for 7 Months

Clients decide whether they made the right choice within the first week. A structured onboarding process makes them confident. A chaotic one makes them nervous — and nervous clients scrutinize every invoice, question every decision, and leave at the first opportunity.

This checklist covers every step from signed contract to first deliverable. Copy it, adapt it to your business, and automate the repetitive parts.

## Phase 1: Pre-Onboarding (Before Contract Signature)

**Goal:** Set expectations so there are no surprises after signing.

- [ ] Proposal clearly defines scope, deliverables, timeline, and pricing
- [ ] Payment terms documented (deposit amount, schedule, late fees)
- [ ] Communication expectations stated (response time, preferred channels, meeting cadence)
- [ ] What you need from the client listed (assets, access, decisions, availability)
- [ ] Contract sent via e-signature tool (DocuSign, PandaDoc, HelloSign)
- [ ] Contract reminder scheduled if unsigned after 3 days

## Phase 2: Day 0 — Contract Signed

**Goal:** Immediate acknowledgment. The client should feel the machine start moving within hours.

- [ ] Welcome email sent within 1 hour (what happens next, who their contact is, timeline overview)
- [ ] Deposit invoice sent
- [ ] Client intake form sent (brand assets, login credentials, stakeholder contacts, goals, constraints)
- [ ] Internal team notified via Slack or email
- [ ] Project created in project management tool from template
- [ ] Shared folder created (Google Drive, Dropbox) with organized subfolders
- [ ] Communication channel set up (Slack Connect channel, client portal, or dedicated email thread)
- [ ] Kickoff call scheduling link sent

**Automation:** Every step in this phase can be triggered automatically when the contract is signed or the deal is marked "Won" in your CRM. ## Phase 3: Days 1-3 — Information Gathering

**Goal:** Collect everything you need to start work without repeated back-and-forth.

- [ ] Intake form completed (send reminder if not done by day 2)
- [ ] Brand assets received (logo files, brand guidelines, fonts, color codes)
- [ ] Access credentials received (website admin, analytics, ad accounts, social media)
- [ ] Access verified — log in and confirm each account works
- [ ] Stakeholder list confirmed (who approves, who provides input, who receives updates)
- [ ] Existing materials reviewed (previous work, competitor references, past performance data)
- [ ] Questions compiled for kickoff call

**Automation:** Intake form submission → data populated into project brief document + confirmation email sent to client + team notified. Missing access after 48 hours → automated reminder.

## Phase 4: Day 3-5 — Kickoff Call

**Goal:** Align on goals, process, and expectations face-to-face (or screen-to-screen).

**Kickoff agenda:**
- [ ] Introductions (team members, roles, who does what)
- [ ] Goals review (what does success look like in 30, 90, 180 days?)
- [ ] Process walkthrough (how you work, milestone schedule, review cycles)
- [ ] Communication plan (weekly updates, meeting cadence, how to reach you)
- [ ] Questions from intake review
- [ ] Immediate next steps and dates

**Post-kickoff:**
- [ ] Meeting notes sent within 4 hours (decisions, action items with owners and dates)
- [ ] Project timeline updated based on kickoff discussion
- [ ] First milestone tasks assigned to team
- [ ] Calendar invites sent for recurring check-ins

**Automation:** Kickoff call ends → meeting notes template generated + calendar invites for recurring meetings created + first milestone tasks assigned from project template.

## Phase 5: Days 5-14 — First Deliverable

**Goal:** Deliver something tangible quickly. Early wins build trust.

- [ ] First deliverable defined (something visible within 2 weeks — a wireframe, a content plan, an audit, a strategy doc)
- [ ] Internal review before client sees it
- [ ] Deliverable presented with context (what it is, why it matters, what happens next)
- [ ] Feedback requested with clear deadline
- [ ] Feedback incorporated and confirmed
- [ ] Weekly status update sent (every Friday, same format every time)

**Automation:** Task marked complete in project tool → client notification. Friday 2 PM → status update template pre-filled with completed tasks, sent to account manager for review.

## Phase 6: Day 14-30 — Rhythm Established

**Goal:** Transition from onboarding to steady-state delivery.

- [ ] Regular meeting cadence running (weekly or biweekly check-ins)
- [ ] Status updates consistent (client knows exactly when to expect them)
- [ ] Client satisfaction check (informal: "How are we doing? Anything we should adjust?")
- [ ] Internal retrospective (what worked in onboarding, what to improve for next client)
- [ ] Onboarding checklist archived to project documentation

**Automation:** Day 30 → satisfaction survey sent + internal retrospective task created. Response below 8/10 → escalation to agency lead.

## Onboarding Templates by Business Type

**Marketing Agency:** Add steps for ad account access, pixel installation verification, analytics setup, competitor analysis, and content calendar creation.

**Web Development:** Add hosting setup, domain access, staging environment creation, design system review, and technical requirements documentation.

**Consulting:** Add stakeholder interviews, data access requests, current-state documentation, and engagement charter.

**Coaching/Training:** Add assessment completion, goal-setting session, program schedule, and resource library access.

**Bookkeeping/Accounting:** Add bank account connection, prior-year financials review, chart of accounts setup, and software migration.

## What should a client onboarding checklist include?

Six phases: (1) pre-contract expectation setting, (2) immediate post-signature acknowledgment (welcome email, invoice, intake form, project setup), (3) information gathering (assets, credentials, stakeholders), (4) kickoff call with agenda and follow-up notes, (5) first deliverable within 2 weeks, and (6) rhythm establishment with regular updates and a 30-day satisfaction check. Total: roughly 35 steps, of which 80% can be [automated](/blog/automate-customer-onboarding) with tools like Make or Zapier so every client receives the same consistent experience.

## How long should client onboarding take?

Target 14 days from contract signature to first deliverable, with the kickoff call within 3-5 days. Longer onboarding periods create anxiety — clients wonder if they made the right choice. Faster is better but should not skip information gathering. The first 24 hours are critical: welcome email, invoice, and intake form should go out within hours of signing, ideally [automated](/blog/automate-client-intake) so the client experiences immediate momentum regardless of when they sign.
